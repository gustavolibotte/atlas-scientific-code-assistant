# Interface design principles

Design references: five user-supplied dashboard and cloud workspace screenshots, November 2026.
The interface is inspired by their spatial organization and restraint, not a reproduction.

- Permanent left navigation for Overview, Workspace, Evidence, Validation, and Settings.
- Clear information hierarchy, large content surfaces, muted violet and blue accents.
- Rounded cards, subtle shadows, consistent spacing, responsive two-column workspace.
- The scientific workflow takes priority over decorative business KPIs.
- Every capability must display its actual state; synthetic records must be visibly labeled.
- Keyboard-accessible controls, visible focus styles, semantic headings, reduced-motion support.
- Desktop-first arrangement with a mobile-friendly stacked layout.
- No external image assets, brand logos, or proprietary typography are required for Phase 0.

The chat input is a local draft preview only until an agent backend is implemented.
